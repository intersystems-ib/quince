# Lesiones

Las bajas ocurren en partidos y entrenamientos; influyen edad, fatiga, intensidad y preparación. El riesgo base de partido es 0,000045 por jugador y veinte segundos. Son parámetros de simulación.

| Lesión | Grado | Semanas |
| --- | --- | --- |
| Contusión | 1 / 2 | 1 / 1–2 |
| Sobrecarga muscular | 1 | 1–2 |
| Contractura muscular | 1 | 1–2 |
| Esguince de tobillo | 1 / 2 / 3 | 1–2 / 3–5 / 8–12 |
| Lesión de fibras musculares | 1 / 2 | 1–2 / 3–6 |
| Rotura muscular | 3 | 10–16 |
| Lesión de aductores | 2 | 2–4 |
| Lesión de isquiotibiales | 2 | 3–6 |
| Esguince de hombro | 2 | 2–4 |
| Luxación de hombro | 3 | 6–10 |
| Conmoción cerebral | 2 | 2–4 |
| Lesión de menisco | 3 | 6–10 |
| Fractura de clavícula | 3 | 8–12 |
| Fractura de tobillo | 3 | 12–18 |
| Rotura de ligamento cruzado | 3 | 28–40 |
| Rotura del tendón de Aquiles | 3 | 24–36 |

La cruz roja identifica lesionados. Los suplentes de baja pasan automáticamente a «No disponibles»; los titulares deben ser reemplazados. Al recuperarse, el jugador conserva su historial y pasa al banquillo si hay menos de ocho suplentes; si está completo, aparece en «No convocados». Si sigue figurando como titular, conserva su puesto.

Durante la baja recupera energía y no entrena atributos. Una lesión propia pausa el partido; se reanuda eligiendo velocidad. Durante el encuentro se identifica al lesionado; su diagnóstico y duración de baja se consultan en la ficha y las pantallas de gestión. El rival usa las mismas reglas de lesiones y disponibilidad.
