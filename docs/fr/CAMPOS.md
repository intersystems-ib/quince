# Stades et capacités

[Español](../CAMPOS.md) · [English](../en/CAMPOS.md) · [Français](CAMPOS.md) · [Index](README.md)

Références publiées pour 2026/27, consultées le 10 novembre 2026 : [Honor](https://es.wikipedia.org/wiki/Divisi%C3%B3n_de_Honor_de_rugby_2026-27) et [Élite](https://es.wikipedia.org/wiki/Divisi%C3%B3n_de_Honor_%C3%89lite_de_rugby_2026-27). `../../iris/data/venues.json` conserve nom du stade, capacité, saison, date de consultation et source pour les vingt clubs. Les capacités proviennent de ces publications, pas d'une vérification administrative des jauges.

Les clubs conservent leur stade lors d'un changement de division. Chaque rencontre enregistre celui du recevant ; les anciens enregistrements sans stade utilisent ses données. Ces informations apparaissent dans le centre du club, annuaire, calendrier, compétition, avant-match et tableau de score. Les données manquantes sont indiquées comme indisponibles.
