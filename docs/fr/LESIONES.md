# Blessures

[Español](../LESIONES.md) · [English](../en/LESIONES.md) · [Français](LESIONES.md) · [Index](README.md)

Les blessures surviennent en match et à l'entraînement, selon âge, fatigue, intensité et préparation. Le risque de base en match est de 0,000045 par joueur et par vingt secondes. Ce sont des paramètres de jeu.

| Blessure | Degré | Semaines |
|---|---|---|
| Contusion | 1 / 2 | 1 / 1–2 |
| Surcharge musculaire | 1 | 1–2 |
| Contracture musculaire | 1 | 1–2 |
| Entorse de la cheville | 1 / 2 / 3 | 1–2 / 3–5 / 8–12 |
| Lésion des fibres musculaires | 1 / 2 | 1–2 / 3–6 |
| Déchirure musculaire | 3 | 10–16 |
| Lésion des adducteurs | 2 | 2–4 |
| Lésion des ischio-jambiers | 2 | 3–6 |
| Entorse de l'épaule | 2 | 2–4 |
| Luxation de l'épaule | 3 | 6–10 |
| Commotion cérébrale | 2 | 2–4 |
| Lésion du ménisque | 3 | 6–10 |
| Fracture de la clavicule | 3 | 8–12 |
| Fracture de la cheville | 3 | 12–18 |
| Rupture du ligament croisé | 3 | 28–40 |
| Rupture du tendon d'Achille | 3 | 24–36 |

Une croix rouge identifie les blessés. Les remplaçants blessés passent automatiquement dans **Indisponibles** ; les titulaires doivent être remplacés. Au retour, l'historique est conservé et le joueur rejoint le banc s'il compte moins de huit joueurs, sinon **Non convoqués**. S'il figure toujours comme titulaire, il garde sa place.

Pendant l'absence, le joueur récupère de l'énergie sans entraîner ses attributs. Une blessure dans votre équipe met le match en pause ; choisissez une vitesse pour reprendre. En jeu, seul le joueur blessé est identifié ; diagnostic et durée sont consultables dans la fiche et les écrans de gestion. Les adversaires suivent les mêmes règles de blessures et disponibilité.
